# 桌面清单

**当前版本：1.6.3（build 20）**。一个本地优先的 macOS 桌面效率工具：清单任务、事项、Mac 日历日程、Mac 提醒事项、番茄钟、月视图和时间统计。最低支持 macOS 13，兼容 Intel 与 Apple 芯片。

“今日”页分为“任务”和“事项”两个子块。同一天连续新建的任务从上一项结束时间接续；首项按最近的整点或半点开始，默认时长为 2 小时。点击“同步任务到日历”后，任务按稳定 ID 新增或更新到所选 Mac 日历，删除项在下一次任务同步时从日历移除。批量选择可删除最近 30 天内的任务。

Mac 日历日程与任务分别管理：日程可从所选 Mac 日历导入，在“管理已导入日程”中修改，再同步回原日历；任务同步只写入所选日历中的 DeskFlow 任务事件，不会被作为日程重复导入。普通日历日程默认隐藏，节假日与二十四节气始终显示。

Mac 提醒事项单独存储：可从 Mac 当前可访问的提醒事项列表导入，在“事项”子块中编辑或新建并双向同步；列表选择动态读取系统清单并显示列表颜色。月历“事项”图层合并本地事项和选中的 Mac 提醒列表，并按关联 ID 去重；即使尚未授权 Mac 提醒事项，本地事项仍会显示。没有截止日期的 Mac 提醒事项按创建日期归入当天，不会产生跨天事项。事项不会同步到 Mac 日历；事项、任务与日历日程不会互相复制。

## 数据位置

`~/Library/Application Support/DeskFlow/data.json`

应用会在每次数据或计时变化后自动保存至 `data.json`。旧版数据会原子迁移为独立的任务、日历日程和事项结构；专注记录、计时状态与分别分类的删除重试队列会保留。右上角 `…` 可以导出完整 JSON 备份或仅含任务的 CSV。日历日程导入、修改和回写以及清单任务同步均位于“今日 · 任务”；提醒事项同步位于“今日 · 事项”。月历页只负责显示和切换图层。

## 构建

```bash
chmod +x build.sh
./build.sh
```

构建结果同时支持 Intel 和 Apple 芯片 Mac。要求 macOS 13 或更高版本，以及 Apple Command Line Tools。
