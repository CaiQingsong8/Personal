# 桌面清单

一个本地优先的 macOS 桌面效率工具：ToDo、番茄钟、月视图、时间统计，以及由用户主动触发的 Mac 日历互传。

主界面名称默认为“小唐日程”。名字可在右上角 `…` 中修改，例如输入“张三”后，主标题和专用日历都会使用“张三日程”。任务日期通过整块按钮弹出图形日历选择，避免误改年月；也可选择具体时间，定时任务默认 1 小时并以 30 分钟为步长调整。月历底部可以分别显示或隐藏任务、普通 Mac 日历行程和专注记录；节日始终显示，已关联清单的日历副本只显示清单事项。日历互传以任务 UUID 保持同一事项关联；同步会跨日历查找唯一的原行程，并移入当前所选日历后更新，避免同一任务在多个日历重复。任务支持批量选择最近 30 天并确认删除，关联行程会在下次同步时删除。

## 数据位置

`~/Library/Application Support/DeskFlow/data.json`

应用会在每次任务或计时变化后自动保存。右上角 `…` 可以导出完整 JSON 备份或 CSV 任务表；Mac 日历互传入口位于月历底部。

## 构建

```bash
chmod +x build.sh
./build.sh
```

构建结果同时支持 Intel 和 Apple 芯片 Mac。要求 macOS 13 或更高版本，以及 Apple Command Line Tools。
