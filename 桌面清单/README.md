# 桌面清单

一个本地优先的 macOS 桌面效率工具：本地清单、Mac 日历日程、Mac 提醒事项、番茄钟、月视图和时间统计。最低支持 macOS 13，兼容 Intel 与 Apple 芯片。

“今日”页分为“清单”和“提醒事项”两个子块。新建清单任务默认从最近的整点或半点开始，时长为 2 小时；清单任务只保存在本地，不会写入 Mac 日历或 Mac 提醒事项。批量选择可删除最近 30 天内的本地清单任务。

Mac 日历日程与清单独立：可从所选 Mac 日历导入，在“管理已导入日程”中修改，再同步回 Mac 日历；日历同步以稳定 UUID 和 EventKit 标识更新现有事件。普通日历日程默认隐藏，节假日与二十四节气始终显示。

Mac 提醒事项也单独存储：可从所选列表导入，在“提醒事项”子块中编辑或新建并双向同步；没有截止日期的 Mac 提醒事项按创建日期归入当天，不会产生跨天事项。提醒事项和日历日程不会互相复制。

## 数据位置

`~/Library/Application Support/DeskFlow/data.json`

应用会在每次数据或计时变化后自动保存至 `data.json`。旧版数据会原子迁移为独立的本地清单、日历日程和提醒事项结构；专注记录、计时状态与删除重试队列会保留。右上角 `…` 可以导出完整 JSON 备份或仅含本地清单任务的 CSV。Mac 日历和提醒事项的连接、导入及同步面板位于月历页底部。

## 构建

```bash
chmod +x build.sh
./build.sh
```

构建结果同时支持 Intel 和 Apple 芯片 Mac。要求 macOS 13 或更高版本，以及 Apple Command Line Tools。
