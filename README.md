## 版本命名规则

- 小唐：Release 标题 `01 小唐宠物 · 版本号`；新版本使用一个 `01-xiaotang-v版本号` Tag。
- 桌面清单：Release 标题 `02 桌面清单 · 版本号`；新版本使用一个 `02-deskflow-v版本号` Tag。
- 其他项目依次使用 `03`、`04`……及稳定的项目英文标识；`03` 已分配给广州城际与地铁检索项目。
- 历史 `v...` Tag 与原 Release 链接保留，每个历史版本不再额外创建编号别名。Tag 标记整个仓库，自动生成的源码包可能包含其他项目。
- GitHub 的 Releases 和 Tags 是仓库级列表，原生页面不能固定按项目编号排序；草稿仅供有权限的人查看。每个项目的安装包请从上述项目版本入口查找。
